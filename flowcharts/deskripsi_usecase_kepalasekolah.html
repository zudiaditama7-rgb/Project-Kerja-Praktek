Tabel 1. Deskripsi Use Case Melakukan Login
Nama use case Melakukan Login
Kebutuhan Pengguna harus dapat mengakses sistem dengan kredensial yang valid
Tujuan Memberikan akses ke dalam sistem dengan hak otorisasi tertinggi (Kepala Sekolah)
Prekondisi Kepala Sekolah belum masuk ke dalam sistem (berada di halaman login)
Kondisi Gagal Username atau password salah
Aktor Utama Kepala Sekolah
Arus Utama 1. Pengguna membuka halaman login
2. Mengisi username dan password
3. Sistem memverifikasi validitas data
4. Pengguna diarahkan ke dashboard Kepala Sekolah
Post Kondisi Kepala Sekolah berhasil masuk ke sistem dan mendapatkan akses penuh ke laporan
Tabel 2. Deskripsi Use Case Melihat Dashboard
Nama use case Melihat Dashboard
Kebutuhan Kepala Sekolah dapat melihat ringkasan eksekutif (executive summary) dari data presensi sekolah
Tujuan Menyediakan indikator kinerja utama (KPI) tingkat kehadiran seluruh siswa secara visual
Prekondisi Kepala Sekolah sudah berhasil login ke sistem
Kondisi Gagal Sistem gagal memuat grafik dan statistik dari database
Aktor Utama Kepala Sekolah
Arus Utama 1. Sistem menampilkan halaman dashboard utama
2. Kepala Sekolah melihat grafik ringkasan kehadiran harian dan metrik sekolah
Post Kondisi Kepala Sekolah mendapatkan informasi analitik global tentang kondisi sekolahnya
Tabel 3. Deskripsi Use Case Mengelola Profil
Nama use case Mengelola Profil
Kebutuhan Kepala Sekolah dapat memperbarui informasi akun dan mengamankan password
Tujuan Menjaga kerahasiaan dan keamanan akun pemangku jabatan tertinggi di sistem
Prekondisi Kepala Sekolah sedang berada di dalam sistem
Kondisi Gagal Gagal menyimpan karena password baru tidak memenuhi standar keamanan
Aktor Utama Kepala Sekolah
Arus Utama 1. Memilih menu Profil/Pengaturan Akun
2. Memperbarui informasi atau kata sandi
3. Sistem menyimpan dan memvalidasi perubahan
Post Kondisi Data profil atau kata sandi Kepala Sekolah berhasil diperbarui
Tabel 4. Deskripsi Use Case Monitoring Presensi Harian
Nama use case Monitoring Presensi Harian
Kebutuhan Kepala Sekolah dapat memantau kedisiplinan pengisian presensi oleh guru/wali kelas secara real-time
Tujuan Sebagai bentuk pengawasan (supervisi) terhadap kelancaran proses absensi harian
Prekondisi Kepala Sekolah memiliki akses ke menu monitoring
Kondisi Gagal Data monitoring kosong atau tidak termuat
Aktor Utama Kepala Sekolah
Arus Utama 1. Kepala Sekolah membuka menu Monitoring Presensi
2. Sistem menampilkan tabel status kelas (sudah diabsen atau belum)
3. Kepala Sekolah memantau kelas mana yang sering terlambat melapor
Post Kondisi Kepala Sekolah mengetahui status operasional pengisian presensi hari tersebut
Tabel 5. Deskripsi Use Case Filter Data Per Kelas/Periode
Nama use case Filter Data Per Kelas/Periode
Kebutuhan Kepala Sekolah harus bisa memilah tampilan monitoring berdasarkan rentang waktu atau kelas tertentu
Tujuan Mempermudah pencarian dan analisis spesifik pada kelas atau bulan yang difokuskan
Prekondisi Kepala Sekolah sedang berada di halaman Monitoring Presensi
Kondisi Gagal Sistem tidak menemukan data pada parameter filter yang dimasukkan
Aktor Utama Kepala Sekolah
Arus Utama 1. Kepala Sekolah memilih dropdown/opsi filter (misal: "Bulan Lalu", "Kelas 3")
2. Menekan tombol Terapkan Filter
3. Sistem menyaring ulang tabel data sesuai kriteria
Post Kondisi Tabel monitoring menampilkan data spesifik sesuai parameter filter
Tabel 6. Deskripsi Use Case Approval Laporan Rekap
Nama use case Approval Laporan Rekap
Kebutuhan Kepala Sekolah harus memeriksa dan menyetujui laporan presensi bulanan yang diajukan oleh wali kelas
Tujuan Sebagai legalisasi (pengesahan) bahwa laporan absensi bulan tersebut sah dan valid
Prekondisi Ada laporan rekap presensi berstatus "Menunggu Persetujuan" dari wali kelas
Kondisi Gagal Gagal memuat dokumen laporan atau gagal mengubah status di database
Aktor Utama Kepala Sekolah
Arus Utama 1. Kepala Sekolah membuka notifikasi pengajuan Approval Laporan Rekap
2. Memeriksa ringkasan dan detail laporan absensi bulanan tersebut
3. Memutuskan untuk menyetujui (Approve) atau menolak (Reject) laporan
Post Kondisi Laporan rekapitulasi berpindah status dari proses peninjauan
Tabel 7. Deskripsi Use Case Approve Laporan
Nama use case Approve Laporan
Kebutuhan Kepala Sekolah mensahkan/menyetujui laporan yang sudah benar
Tujuan Melegalisasi dokumen laporan bulanan agar bisa diarsip/dicetak secara resmi
Prekondisi Kepala Sekolah sedang meninjau form pengajuan Approval Laporan Rekap
Kondisi Gagal Sistem gagal membubuhkan tanda tangan digital/status persetujuan
Aktor Utama Kepala Sekolah
Arus Utama 1. Kepala Sekolah menekan tombol "Approve" (Setuju)
2. Sistem mengubah status laporan menjadi "Disetujui"
3. Sistem mengirimkan notifikasi persetujuan kepada Wali Kelas pemohon
Post Kondisi Laporan resmi disahkan oleh Kepala Sekolah
Tabel 8. Deskripsi Use Case Reject Laporan
Nama use case Reject Laporan
Kebutuhan Kepala Sekolah berhak menolak laporan jika ditemukan ketidaksesuaian data
Tujuan Mencegah pengesahan laporan yang salah dan meminta wali kelas melakukan revisi
Prekondisi Kepala Sekolah sedang meninjau form pengajuan Approval Laporan Rekap
Kondisi Gagal Pesan penolakan gagal terkirim ke Wali Kelas
Aktor Utama Kepala Sekolah
Arus Utama 1. Kepala Sekolah menekan tombol "Reject" (Tolak)
2. Memasukkan alasan penolakan/catatan revisi
3. Sistem mengubah status menjadi "Ditolak/Revisi"
4. Mengirim notifikasi ke Wali Kelas
Post Kondisi Laporan ditolak dan dikembalikan ke Wali Kelas untuk diperbaiki
Tabel 9. Deskripsi Use Case Melihat Laporan Presensi
Nama use case Melihat Laporan Presensi
Kebutuhan Kepala Sekolah dapat mengakses seluruh rekapitulasi data kehadiran sekolah secara mendetail
Tujuan Bahan evaluasi kedisiplinan dan laporan ke instansi yang lebih tinggi (Dinas Pendidikan)
Prekondisi Kepala Sekolah membuka menu Laporan Presensi
Kondisi Gagal Sistem gagal mengkalkulasi rekap karena beban data yang besar (timeout)
Aktor Utama Kepala Sekolah
Arus Utama 1. Kepala Sekolah mengatur filter (semester/tahun/kelas)
2. Sistem memuat tabel rekap total ketidakhadiran dan kehadiran
3. Kepala Sekolah meninjau hasil kalkulasi laporan tersebut
Post Kondisi Tabel laporan lengkap berhasil ditampilkan
Tabel 10. Deskripsi Use Case Download Laporan PDF
Nama use case Download Laporan PDF
Kebutuhan Kepala Sekolah membutuhkan salinan hardcopy/digital laporan presensi sekolah
Tujuan Menyediakan dokumen berformat baku dengan kop surat sekolah dan tanda tangan sah
Prekondisi Kepala Sekolah sedang melihat hasil tabel Laporan Presensi
Kondisi Gagal Proses pembuatan (rendering) PDF gagal atau layout tabel rusak
Aktor Utama Kepala Sekolah
Arus Utama 1. Menekan tombol "Cetak Laporan / PDF"
2. Sistem memformat data ke dalam template laporan resmi (termasuk kolom pengesahan)
3. Dokumen PDF terunduh ke komputer Kepala Sekolah
Post Kondisi Laporan kehadiran siap dicetak sebagai dokumen legal sekolah
Tabel 11. Deskripsi Use Case Melihat Statistik Kehadiran
Nama use case Melihat Statistik Kehadiran
Kebutuhan Kepala Sekolah dapat melihat performa kedisiplinan sekolah dalam bentuk grafik tren waktu
Tujuan Membantu pembuatan keputusan (Decision Support) terkait evaluasi kedisiplinan siswa atau guru
Prekondisi Kepala Sekolah membuka menu Statistik Analitik
Kondisi Gagal Gagal me-render chart visualisasi
Aktor Utama Kepala Sekolah
Arus Utama 1. Kepala Sekolah mengakses halaman Statistik
2. Sistem memuat grafik garis/batang yang merepresentasikan tren tingkat kehadiran dan alpa dari bulan ke bulan
3. Kepala Sekolah membaca informasi visual tersebut
Post Kondisi Grafik statistik kehadiran sekolah berhasil ditampilkan
Tabel 12. Deskripsi Use Case Melakukan Logout
Nama use case Melakukan Logout
Kebutuhan Kepala Sekolah dapat keluar dari sistem dengan aman
Tujuan Menjaga kerahasiaan data laporan dan otorisasi dari pihak tak berwenang
Prekondisi Kepala Sekolah dalam keadaan login dan berada di dalam sistem
Kondisi Gagal Sesi gagal dihapus secara total (sesi masih menggantung)
Aktor Utama Kepala Sekolah
Arus Utama 1. Kepala Sekolah menekan menu Profil dan memilih Logout
2. Sistem menghancurkan session login
3. Mengarahkan kembali ke halaman utama
Post Kondisi Kepala Sekolah telah aman keluar dari sistem aplikasi
