Tabel 1. Deskripsi Use Case Melakukan Login
Nama use case Melakukan Login
Kebutuhan Pengguna harus dapat mengakses sistem menggunakan kredensial yang dimilikinya
Tujuan Memberikan akses ke dalam sistem sesuai hak akses Guru Pengganti
Prekondisi Guru Pengganti belum masuk ke dalam sistem (berada di halaman login)
Kondisi Gagal Username atau password salah, atau akun sedang dinonaktifkan
Aktor Utama Guru Pengganti
Arus Utama 1. Pengguna membuka halaman login
2. Mengisi username dan password
3. Sistem memverifikasi validitas data
4. Pengguna diarahkan ke dashboard
Post Kondisi Guru Pengganti berhasil login ke dalam sistem
Tabel 2. Deskripsi Use Case Melihat Dashboard
Nama use case Melihat Dashboard
Kebutuhan Guru Pengganti dapat melihat notifikasi dan ringkasan kelas yang harus diajarnya hari ini
Tujuan Menyediakan informasi langsung (quick-view) mengenai tugas penggantian aktif
Prekondisi Guru Pengganti sudah berhasil login
Kondisi Gagal Sistem gagal memuat data penugasan dari database
Aktor Utama Guru Pengganti
Arus Utama 1. Sistem menampilkan halaman dashboard
2. Guru Pengganti melihat ringkasan tugas kelas yang didelegasikan kepadanya
Post Kondisi Guru Pengganti mengetahui secara sekilas jadwal penggantian yang harus dilakukannya
Tabel 3. Deskripsi Use Case Mengelola Profil
Nama use case Mengelola Profil
Kebutuhan Guru Pengganti dapat memperbarui data kontak atau mengubah kata sandi
Tujuan Memastikan data kredensial dan keamanan akun tetap terjaga
Prekondisi Guru Pengganti berada di dalam sistem
Kondisi Gagal Gagal menyimpan karena koneksi terputus atau format password salah
Aktor Utama Guru Pengganti
Arus Utama 1. Memilih menu Profil
2. Memperbarui isian data atau password baru
3. Sistem memvalidasi dan menyimpan ke database
Post Kondisi Data profil akun Guru Pengganti berhasil di-update
Tabel 4. Deskripsi Use Case Melihat Tugas Penggantian
Nama use case Melihat Tugas Penggantian
Kebutuhan Guru Pengganti dapat mengakses detail instruksi dan mengunduh materi dari guru asli yang berhalangan
Tujuan Sebagai panduan mengajar agar materi pembelajaran di kelas yang digantikan tidak terputus
Prekondisi Admin sudah menetapkan (assign) Guru Pengganti ke kelas tertentu
Kondisi Gagal Detail tugas tidak tampil atau lampiran dokumen gagal diunduh
Aktor Utama Guru Pengganti
Arus Utama 1. Guru Pengganti membuka menu Tugas Penggantian
2. Memilih penugasan yang aktif
3. Membaca instruksi mengajar dan mengunduh berkas lampiran materi
Post Kondisi Guru Pengganti mendapatkan materi yang harus disampaikan di kelas
Tabel 5. Deskripsi Use Case Input Presensi Pengganti
Nama use case Input Presensi Pengganti
Kebutuhan Guru Pengganti diberikan wewenang sementara untuk mencatat presensi kelas yang digantikannya
Tujuan Memastikan data kehadiran siswa tetap direkam meski guru asli tidak hadir
Prekondisi Guru Pengganti berada di jam mengajar kelas pengganti
Kondisi Gagal Sistem memblokir akses input karena jam mengajar sudah lewat atau jadwal salah
Aktor Utama Guru Pengganti
Arus Utama 1. Guru Pengganti membuka menu Presensi
2. Sistem hanya menampilkan kelas yang ditugaskan kepadanya
3. Menentukan metode absensi (Scan QR atau Manual)
4. Sistem menyimpan data kehadiran ke database
Post Kondisi Kehadiran siswa di kelas pengganti berhasil dicatat
Tabel 6. Deskripsi Use Case Presensi via QR Code (Scan)
Nama use case Presensi via QR Code (Scan)
Kebutuhan Guru Pengganti memindai QR Code siswa pada kelas sementara tersebut
Tujuan Pencatatan presensi yang cepat dan akurat menggunakan pemindai QR
Prekondisi Guru Pengganti berada di form presensi kelas penugasan dan kamera aktif
Kondisi Gagal Kartu siswa rusak atau QR Code ditolak karena siswa dari kelas lain
Aktor Utama Guru Pengganti
Arus Utama 1. Memilih mode Scan QR Code
2. Mengarahkan ID Card siswa ke kamera
3. Sistem memverifikasi siswa tersebut adalah anggota kelas penugasan
4. Status kehadiran langsung tersimpan
Post Kondisi Kehadiran siswa tercatat lewat scan QR oleh Guru Pengganti
Tabel 7. Deskripsi Use Case Presensi via Manual (Form)
Nama use case Presensi via Manual (Form)
Kebutuhan Guru Pengganti menginput presensi secara manual lewat form centang/daftar hadir
Tujuan Sebagai solusi apabila pemindaian QR Code mengalami kendala teknis
Prekondisi Guru Pengganti berada di form presensi kelas penugasan
Kondisi Gagal Gagal tersimpan karena masalah konektivitas server
Aktor Utama Guru Pengganti
Arus Utama 1. Membuka form presensi manual
2. Memilih status kehadiran (Hadir/Sakit/Izin/Alpa) dari daftar nama siswa
3. Menyimpan data absensi
Post Kondisi Presensi kelas penugasan berhasil dilengkapi secara manual
Tabel 8. Deskripsi Use Case Melihat Riwayat Presensi
Nama use case Melihat Riwayat Presensi
Kebutuhan Guru Pengganti dapat melihat riwayat absensi yang pernah ia catat selama ia bertugas
Tujuan Sebagai konfirmasi bahwa data presensi yang ia masukkan sebelumnya sudah benar tersimpan
Prekondisi Guru Pengganti sudah pernah menyelesaikan proses input presensi
Kondisi Gagal Sistem gagal memfilter riwayat sesuai akun yang meminta
Aktor Utama Guru Pengganti
Arus Utama 1. Mengakses menu Riwayat Presensi
2. Sistem menampilkan log/laporan kelas mana saja yang sudah selesai diabsen oleh guru tersebut
Post Kondisi Guru Pengganti dapat memvalidasi log aktivitas mengajarnya
Tabel 9. Deskripsi Use Case Melihat Data Siswa Kelas
Nama use case Melihat Data Siswa Kelas
Kebutuhan Guru Pengganti membutuhkan data profil/identitas siswa di kelas yang ditugaskan kepadanya
Tujuan Membantu Guru Pengganti mengenali siswa di kelas yang belum familiar baginya
Prekondisi Status penugasan ke kelas tersebut masih aktif
Kondisi Gagal Data siswa tidak muncul akibat kesalahan hak akses
Aktor Utama Guru Pengganti
Arus Utama 1. Guru Pengganti membuka menu Data Siswa Kelas
2. Sistem hanya mengizinkan akses ke daftar siswa pada kelas penggantian yang aktif
3. Sistem menampilkan nama dan informasi siswa
Post Kondisi Data siswa berhasil ditampilkan sesuai kelas penugasan sementara
Tabel 10. Deskripsi Use Case Cetak Kartu Siswa QR
Nama use case Cetak Kartu Siswa QR
Kebutuhan Guru Pengganti dapat men-generate ulang kartu QR untuk siswa di kelas tersebut (jika darurat/hilang)
Tujuan Agar siswa yang kartunya tertinggal/hilang tetap bisa dibuatkan kartu pengganti saat itu juga
Prekondisi Guru Pengganti sedang melihat menu Data Siswa Kelas
Kondisi Gagal Sistem gagal men-generate file gambar/PDF untuk kartu siswa
Aktor Utama Guru Pengganti
Arus Utama 1. Memilih nama siswa yang kehilangan kartu
2. Menekan Cetak Kartu QR
3. Sistem membuat ID card beserta QR Code-nya
Post Kondisi Kartu siswa siap didistribusikan (cetak/unduh PDF)
Tabel 11. Deskripsi Use Case Melakukan Logout
Nama use case Melakukan Logout
Kebutuhan Guru Pengganti dapat menghentikan sesi setelah pekerjaannya selesai
Tujuan Mengamankan akun dari potensi akses tak bertanggung jawab
Prekondisi Guru Pengganti masih dalam keadaan login
Kondisi Gagal Browser error dan gagal membersihkan cookie sesi
Aktor Utama Guru Pengganti
Arus Utama 1. Menekan tombol Logout di menu navigasi
2. Sistem menghapus sesi autentikasi
3. Pengguna dikembalikan ke layar Login awal
Post Kondisi Guru Pengganti keluar dari sistem dengan aman
