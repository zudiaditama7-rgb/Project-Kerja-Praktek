No Nama Use Case Deskripsi / Tujuan Singkat

Tabel 3.2 Deskripsi Use Case Admin
No Nama Use Case Deskripsi / Tujuan Singkat
1Melakukan LoginMengakses sistem dengan kredensial berhak akses tingkat administrator.
2Melihat DashboardMemantau ringkasan metrik dan statistik operasional sistem secara keseluruhan.
3Mengelola ProfilMengamankan dan memperbarui akun serta kata sandi pribadi administrator.
4Mengelola Data SiswaMengelola data induk dan riwayat siswa di database (Tambah/Edit/Hapus).
5Import Data Siswa (Excel)(Extend) Memasukkan data pendaftaran siswa massal secara cepat melalui format Excel.

7Cetak Kartu Siswa QR(Extend) Memproduksi kartu ID fisik berisi QR Code untuk kebutuhan scan presensi siswa.
8Mengelola Data KelasMengorganisir daftar rombongan belajar dan menugaskan wali kelasnya.
9Mengelola Tahun AjaranMenambah dan menentukan batas aktif periode akademik/semester berjalan.
10Mengelola PenggunaMelihat daftar seluruh akun stakeholder yang ada di dalam sistem.

14Monitoring PresensiMemantau secara langsung (live) status penyelesaian input absensi harian per kelas.
15Melihat Laporan PresensiMengkalkulasi rekap tingkat kehadiran (Hadir/Sakit/Izin/Alpa) berdasarkan filter waktu.
16Download Laporan PDF(Extend) Men-generate dokumen laporan presensi resmi siap cetak (PDF).
17Memproses Tugas PenggantiMemvalidasi, meninjau, dan memverifikasi pengajuan izin serta tugas dari guru.
18Assign Guru Pengganti(Include) Mendelegasikan dan menunjuk guru lain untuk mengampu jadwal yang kosong.
19Reject Pengajuan(Extend) Menolak pengajuan izin yang dinilai tidak sah/kurang syarat.
20Melakukan LogoutMenutup sesi koneksi admin secara aman.

Aktor Kepala Sekolah berperan di tingkat eksekutif (*top-level*) untuk melakukan pemantauan operasional, analisis kedisiplinan, serta mengesahkan laporan presensi bulanan sekolah.

[ PASTE GAMBAR USE CASE DIAGRAM KEPALA SEKOLAH DI SINI ]
Tabel 3.5 Deskripsi Use Case Kepala Sekolah
No Nama Use Case Deskripsi / Tujuan Singkat
1Melakukan LoginMasuk ke sistem dengan hak akses tingkat eksekutif tertinggi.
2Melihat DashboardMelihat visualisasi awal berupa indikator kinerja (KPI) tingkat kehadiran seluruh sekolah.
3Mengelola ProfilMengamankan akses profil dan memperbarui sandi pimpinan sekolah.

9Melihat Laporan PresensiMenganalisa data rekapitulasi ketidakhadiran siswa (Sakit/Izin/Alpa) di semua kelas.

11Melihat Statistik KehadiranMemvisualisasikan tren kedisiplinan sekolah lewat grafik kurva sebagai alat bantu pembuatan keputusan (*decision support*).
12Melakukan LogoutMenutup akses dashboard eksekutif setelah selesai melakukan supervisi.
