4.9. Perancangan Basis Data

Perancangan basis data dilakukan untuk mendukung kebutuhan sistem dalam mencatat dan mengelola data absensi harian, manajemen siswa, penugasan guru, serta laporan rekapitulasi pada Sistem Informasi Presensi Sekolah. Basis data dirancang menggunakan MySQL, dan mencakup entitas utama seperti users, siswa, kelas, presensi, dan entitas pendukung lainnya.

a. Tabel users

Tabel 4.19 Tabel users
Nama Field Tipe Field Lebar Keterangan
id INT 11 Primary key, auto increment
name VARCHAR 100 Nama lengkap pengguna
username VARCHAR 50 Username untuk login sistem
password VARCHAR 255 Kata sandi pengguna (terenkripsi)
role ENUM - Hak akses (admin, wali_kelas, guru_mapel, dll)
avatar VARCHAR 255 Direktori/URL foto profil pengguna (opsional)

b. Tabel tahun_ajaran

Tabel 4.20 Tabel tahun_ajaran
Nama Field Tipe Field Lebar Keterangan
id INT 11 Primary key, auto increment
user_id INT 11 Foreign key ke tabel users (Admin pembuat)
nama_tahun VARCHAR 50 Contoh: "2023/2024 Genap"
is_active TINYINT 1 Status aktif (1 = Aktif, 0 = Non-aktif)

c. Tabel kelas

Tabel 4.21 Tabel kelas
Nama Field Tipe Field Lebar Keterangan
id INT 11 Primary key, auto increment
wali_kelas_id INT 11 Foreign key ke tabel users (Wali Kelas)
nama_kelas VARCHAR 50 Nama identitas kelas (contoh: 1-A, 2-B)
semester INT 11 Angka penunjuk tingkat semester

d. Tabel siswa

Tabel 4.22 Tabel siswa
Nama Field Tipe Field Lebar Keterangan
id INT 11 Primary key, auto increment
nis VARCHAR 20 Nomor Induk Siswa (Unique)
nama_siswa VARCHAR 100 Nama lengkap peserta didik
status ENUM - Status siswa ('Aktif', 'Lulus', 'Pindah', dll)

e. Tabel rombel (Rombongan Belajar)

Tabel 4.23 Tabel rombel
Nama Field Tipe Field Lebar Keterangan
id INT 11 Primary key, auto increment
siswa_id INT 11 Foreign key ke tabel siswa
kelas_id INT 11 Foreign key ke tabel kelas
tahun_ajaran_id INT 11 Foreign key ke tabel tahun_ajaran

f. Tabel presensi

Tabel 4.24 Tabel presensi
Nama Field Tipe Field Lebar Keterangan
id INT 11 Primary key, auto increment
siswa_id INT 11 Foreign key ke tabel siswa
user_id INT 11 Foreign key ke tabel users (Guru pencatat)
tanggal DATE - Tanggal rekam presensi (YYYY-MM-DD)
nama_mapel VARCHAR 100 Nama mata pelajaran yang sedang diajarkan
status ENUM - Keterangan kehadiran ('Hadir', 'Izin', 'Sakit', 'Alpa')
document_path VARCHAR 255 Path file/foto bukti keterangan (jika sakit/izin)

g. Tabel pengajuan_presensi

Tabel 4.25 Tabel pengajuan_presensi
Nama Field Tipe Field Lebar Keterangan
id INT 11 Primary key, auto increment
user_id INT 11 Foreign key ke tabel users (Guru Pengaju)
tipe VARCHAR 50 Jenis rekapitulasi pengajuan
bulan INT 2 Bulan terjadinya pengajuan (1-12)
tahun INT 4 Tahun pengajuan (contoh: 2024)
status ENUM - Kondisi pengajuan ('Pending', 'Disetujui', 'Ditolak')

h. Tabel tugas_pengganti

Tabel 4.26 Tabel tugas_pengganti
Nama Field Tipe Field Lebar Keterangan
id INT 11 Primary key, auto increment
user_id INT 11 Foreign key ke tabel users (Pemberi Tugas Utama)
guru_mapel_id INT 11 Foreign key ke tabel users (Guru Pengganti)
tanggal DATE - Tanggal tugas dilaksanakan
waktu_mulai TIME - Jam mulai pelajaran
waktu_selesai TIME - Jam selesai pelajaran
alasan TEXT - Deskripsi/alasan ketidakhadiran guru utama
document_path VARCHAR 255 Lampiran tugas/surat izin (opsional)
status ENUM - Status instruksi ('Menunggu', 'Aktif', 'Ditolak', 'Selesai')
keterangan_ditolak TEXT - Alasan penolakan (jika tugas ditolak)

i. Tabel riwayat_siswa

Tabel 4.27 Tabel riwayat_siswa
Nama Field Tipe Field Lebar Keterangan
id INT 11 Primary key, auto increment
siswa_id INT 11 Foreign key ke tabel siswa
tanggal DATE - Tanggal pencatatan riwayat
keterangan TEXT - Detail narasi (contoh: Naik ke Kelas 2-A)
status VARCHAR 50 Label status riwayat saat itu
