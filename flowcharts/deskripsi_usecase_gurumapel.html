Tabel 1. Deskripsi Use Case Melakukan Login
Nama use case Melakukan Login
Kebutuhan Pengguna harus dapat mengakses sistem dengan kredensial yang valid
Tujuan Memberikan akses ke dalam sistem sesuai peran Guru Mata Pelajaran (Mapel)
Prekondisi Guru Mapel belum masuk ke dalam sistem (berada di halaman login)
Kondisi Gagal Username atau password salah, atau akun tidak terdaftar
Aktor Utama Guru Mapel
Arus Utama 1. Pengguna membuka halaman login
2. Mengisi username dan password
3. Sistem memverifikasi validitas data
4. Pengguna diarahkan ke dashboard Guru Mapel
Post Kondisi Guru Mapel berhasil masuk ke sistem dan mendapatkan akses
Tabel 2. Deskripsi Use Case Melihat Dashboard
Nama use case Melihat Dashboard
Kebutuhan Guru Mapel dapat melihat ringkasan jadwal mengajar dan kelas yang diampu
Tujuan Menyediakan informasi awal mengenai jadwal mata pelajaran hari ini secara cepat
Prekondisi Guru Mapel sudah berhasil login ke sistem
Kondisi Gagal Sistem gagal memuat data jadwal/dashboard dari database
Aktor Utama Guru Mapel
Arus Utama 1. Sistem menampilkan halaman dashboard utama
2. Guru Mapel melihat ringkasan kelas dan jadwal pengajarannya
Post Kondisi Guru Mapel mendapatkan gambaran jadwal mengajarnya hari ini
Tabel 3. Deskripsi Use Case Mengelola Profil
Nama use case Mengelola Profil
Kebutuhan Guru Mapel dapat memperbarui data pribadi atau mengganti kata sandi
Tujuan Memastikan data diri Guru Mapel dan akses akun selalu mutakhir
Prekondisi Guru Mapel sedang berada di dalam sistem
Kondisi Gagal Konfirmasi kata sandi tidak cocok saat disimpan
Aktor Utama Guru Mapel
Arus Utama 1. Guru Mapel memilih menu Pengaturan/Profil
2. Mengubah informasi diri atau kata sandi
3. Menyimpan perubahan ke sistem
Post Kondisi Data profil akun Guru Mapel berhasil diperbarui
Tabel 4. Deskripsi Use Case Input Presensi Mata Pelajaran
Nama use case Input Presensi Mata Pelajaran
Kebutuhan Guru Mapel dapat mencatat kehadiran siswa secara khusus pada jam mata pelajarannya
Tujuan Merekam kehadiran siswa berbasis jam pelajaran (bukan hanya kehadiran harian sekolah)
Prekondisi Guru Mapel sudah berada pada jam mengajarnya
Kondisi Gagal Gagal menyimpan data absensi ke database
Aktor Utama Guru Mapel
Arus Utama 1. Guru mapel membuka menu Presensi
2. Memilih kelas mata pelajaran yang diampu (include)
3. Menentukan metode presensi (Scan QR atau Manual)
4. Menyimpan data presensi kelas tersebut
Post Kondisi Kehadiran siswa pada jam pelajaran tersebut berhasil terekam
Tabel 5. Deskripsi Use Case Memilih Kelas Mata Pelajaran
Nama use case Memilih Kelas Mata Pelajaran
Kebutuhan Guru Mapel harus memilih spesifik kelas dan mata pelajaran sebelum melakukan presensi
Tujuan Memastikan data presensi masuk ke rekap yang benar sesuai jadwal kelas
Prekondisi Guru Mapel akan melakukan "Input Presensi Mata Pelajaran"
Kondisi Gagal Jadwal/kelas yang dituju tidak ditemukan di database
Aktor Utama Guru Mapel
Arus Utama 1. Sistem menampilkan daftar jadwal mengajar Guru Mapel
2. Guru Mapel menekan/memilih salah satu kelas yang sedang diampu saat itu
3. Sistem membuka form presensi untuk kelas terpilih
Post Kondisi Target kelas absensi berhasil ditetapkan
Tabel 6. Deskripsi Use Case Presensi via QR Code (Scan)
Nama use case Presensi via QR Code (Scan)
Kebutuhan Guru Mapel dapat memindai QR Code siswa di kelasnya
Tujuan Mempercepat proses presensi per jam pelajaran menggunakan pemindai QR
Prekondisi Guru Mapel sudah memilih kelas dan kamera aktif
Kondisi Gagal QR Code rusak atau kamera perangkat gagal mendeteksi
Aktor Utama Guru Mapel
Arus Utama 1. Guru Mapel memilih metode "Scan QR"
2. Mengarahkan kamera ke ID Card siswa
3. Sistem memvalidasi identitas siswa pada jam pelajaran tersebut
4. Kehadiran siswa tercatat otomatis
Post Kondisi Status kehadiran siswa di jam pelajaran tersebut tersimpan otomatis
Tabel 7. Deskripsi Use Case Presensi via Manual (Form)
Nama use case Presensi via Manual (Form)
Kebutuhan Guru Mapel dapat menginput absensi secara manual melalui daftar hadir
Tujuan Sebagai metode cadangan apabila siswa tidak membawa kartu QR Code
Prekondisi Guru Mapel sudah memilih kelas
Kondisi Gagal Koneksi gagal saat menekan tombol simpan
Aktor Utama Guru Mapel
Arus Utama 1. Guru Mapel memilih metode pengisian presensi manual
2. Memberikan centang status (Hadir, Izin, Sakit, Alpa) pada daftar nama siswa
3. Menyimpan hasil pengisian form
Post Kondisi Kehadiran siswa berhasil terekam secara manual
Tabel 8. Deskripsi Use Case Melihat Data Siswa Kelas
Nama use case Melihat Data Siswa Kelas
Kebutuhan Guru Mapel dapat melihat identitas siswa yang diajarnya
Tujuan Mengenali dan memvalidasi siswa yang ada di kelas yang sedang diampunya
Prekondisi Guru Mapel memiliki jadwal mengajar pada kelas tersebut
Kondisi Gagal Daftar siswa kosong atau tidak termuat dari sistem
Aktor Utama Guru Mapel
Arus Utama 1. Guru mapel membuka menu Data Siswa Kelas
2. Memilih kelas yang diampu
3. Sistem menampilkan daftar anggota siswa di kelas tersebut
Post Kondisi Daftar informasi siswa di kelas yang bersangkutan berhasil ditampilkan
Tabel 9. Deskripsi Use Case Cetak Kartu Siswa QR
Nama use case Cetak Kartu Siswa QR
Kebutuhan Guru Mapel dapat membantu mencetakkan kartu QR siswa (jika diizinkan sistem)
Tujuan Menyediakan duplikat/kartu baru jika siswa di kelas kehilangan QR Codenya
Prekondisi Guru Mapel sedang melihat data siswa di kelasnya
Kondisi Gagal Sistem gagal meng-generate PDF kartu
Aktor Utama Guru Mapel
Arus Utama 1. Guru mapel menyeleksi nama siswa
2. Memilih opsi Cetak Kartu QR
3. Sistem menyusun visual kartu ID beserta barcodenya
4. File siap dicetak/diunduh
Post Kondisi Kartu siswa siap untuk diberikan secara fisik/digital
Tabel 10. Deskripsi Use Case Mengajukan Tugas Pengganti
Nama use case Mengajukan Tugas Pengganti
Kebutuhan Guru Mapel dapat menitipkan tugas/materi jika berhalangan mengajar
Tujuan Memastikan siswa tetap mendapatkan jam pelajaran (tugas) walaupun guru tidak hadir
Prekondisi Guru Mapel masuk sistem namun berhalangan hadir ke sekolah
Kondisi Gagal Form pengajuan gagal tersimpan karena isian tidak lengkap
Aktor Utama Guru Mapel
Arus Utama 1. Guru Mapel membuka form Pengajuan Tugas Pengganti
2. Mengisi instruksi tugas dan kelas tujuan
3. Melakukan upload dokumen materi (include)
4. Mengirimkan pengajuan tugas pengganti ke sistem
Post Kondisi Tugas pengganti berhasil diteruskan ke sistem untuk diproses admin/guru piket
Tabel 11. Deskripsi Use Case Upload Dokumen Pengganti
Nama use case Upload Dokumen Pengganti
Kebutuhan Guru Mapel harus mengunggah file lembar kerja atau materi pelajaran
Tujuan Melengkapi instruksi tekstual dengan berkas tugas riil untuk siswa
Prekondisi Guru Mapel sedang mengisi form Mengajukan Tugas Pengganti
Kondisi Gagal Proses upload terputus atau format file ditolak
Aktor Utama Guru Mapel
Arus Utama 1. Guru Mapel menekan tombol lampiran upload
2. Memilih dokumen (PDF/Word/PPT) dari perangkat
3. Sistem mengunggah file tersebut dan melampirkannya ke pengajuan
Post Kondisi Berkas materi pendukung berhasil dilampirkan pada tugas
Tabel 12. Deskripsi Use Case Mengganti Peran
Nama use case Mengganti Peran (Switch Role)
Kebutuhan Pengguna dengan lebih dari satu jabatan (misal Guru Mapel dan Wali Kelas) dapat bertukar peran tanpa perlu login ulang
Tujuan Mempermudah akses ke berbagai fungsi sistem sesuai dengan peran yang diemban saat itu
Prekondisi Pengguna sudah login dan memiliki lebih dari satu peran di dalam sistem
Kondisi Gagal Sistem gagal memproses pergantian peran atau pengguna hanya memiliki satu peran
Aktor Utama Guru Mapel
Arus Utama 1. Pengguna membuka sidebar menu
2. Pengguna memilih peran yang diinginkan pada dropdown "Peran Aktif"
3. Sistem memproses permintaan dan mengubah sesi (session) peran aktif
4. Sistem memuat ulang halaman dan mengarahkan ke dashboard peran yang dipilih
Post Kondisi Pengguna berhasil berpindah layar dan mendapatkan akses sesuai peran barunya
Tabel 13. Deskripsi Use Case Melakukan Logout
Nama use case Melakukan Logout
Kebutuhan Guru Mapel dapat keluar dari akun sistemnya
Tujuan Mengamankan sesi akun dari pihak yang tidak berkepentingan
Prekondisi Guru Mapel dalam keadaan aktif (login)
Kondisi Gagal Sesi gagal dihancurkan oleh server (error sistem)
Aktor Utama Guru Mapel
Arus Utama 1. Guru Mapel menekan tombol profil/Logout
2. Sistem membersihkan cookies/sesi aktif
3. Layar kembali ke form Login
Post Kondisi Guru Mapel telah keluar dari sistem secara aman
