📋 Flowchart Modul Wali Kelas

Sistem Informasi Presensi Siswa — Dokumentasi Alur Proses Lengkap

Keterangan Simbol Flowchart

Terminator — Mulai / Selesai
Process — Proses / Aksi
Decision — Keputusan / Kondisi
Input/Output — Data masuk/keluar
Database — Simpan ke DB
1

Login & Akses Dashboard Wali Kelas

Wali Kelas login ke sistem, sistem memvalidasi kredensial dan mengecek role. Jika valid, diarahkan ke dashboard yang menampilkan statistik presensi hari ini (Hadir, Izin, Sakit, Alpha, Belum Presensi).

flowchart TD
    A([🟣 Mulai]) --> B[/📥 Input Username & Password/]
    B --> C{🔷 Validasi Kredensial}
    C -->|Gagal| D[⚠️ Tampilkan Pesan Error]
    D --> B
    C -->|Berhasil| E{🔷 Cek Role User}
    E -->|Bukan Wali Kelas| F[🔀 Redirect ke Dashboard Lain]
    E -->|Wali Kelas| G[📊 Ambil Tahun Ajaran Aktif]
    G --> H[📊 Hitung Siswa Aktif via Rombel & Kelas]
    H --> I[📊 Query Presensi Hari Ini]
    I --> J[📊 Hitung Statistik: Hadir, Izin, Sakit, Alpha, Belum]
    J --> K[/📤 Tampilkan Dashboard + Statistik/]
    K --> L([🟣 Selesai])
2

Input Presensi Manual Harian

Wali Kelas membuka halaman presensi, sistem menampilkan daftar siswa aktif di kelasnya. Jika sudah dipresensi oleh Guru Pengganti/Guru Mapel, form terkunci. Jika belum, Wali Kelas mengisi status setiap siswa, upload dokumen jika Izin/Sakit, lalu simpan.

flowchart TD
    A([🟣 Mulai]) --> B[📊 Ambil Periode Semester Aktif]
    B --> C[📊 Ambil Daftar Siswa Aktif di Kelas Wali]
    C --> D[📊 Cek Presensi Hari Ini untuk Semua Siswa]
    D --> E{🔷 Sudah Ada Presensi?}
    E -->|Ya, oleh Guru Pengganti| F[/📤 Tampil Info Guru Pengganti - TERKUNCI/]
    F --> Z([🟣 Selesai])
    E -->|Ya, oleh Guru Mapel| G[/📤 Tampil Info Guru Mapel + Mata Pelajaran - TERKUNCI/]
    G --> Z
    E -->|Belum Ada| H[/📤 Tampilkan Form Presensi/]
    H --> I[/📥 Set Status Tiap Siswa: Hadir / Izin / Sakit / Alpha/]
    I --> J{🔷 Status = Izin atau Sakit?}
    J -->|Ya| K[/📥 Upload Dokumen Pendukung - opsional/]
    K --> L
    J -->|Tidak| L{🔷 Semua Siswa Sudah Terisi?}
    L -->|Tidak| M[⚠️ Error: Status Semua Siswa Harus Diisi]
    M --> I
    L -->|Ya| N[📊 Loop Setiap Siswa]
    N --> O{🔷 Ada File Dokumen?}
    O -->|Ya & Izin/Sakit| P[💾 Simpan File ke Storage]
    P --> Q
    O -->|Tidak atau Hadir/Alpha| Q[💾 updateOrCreate Presensi ke Database]
    Q --> R[/📤 Tampilkan Pesan Sukses/]
    R --> Z
3

Presensi via Scan QR Code

Wali Kelas membuka halaman scan QR, kamera diinisialisasi menggunakan Html5QrcodeScanner. Setiap QR siswa yang di-scan dikirim ke server untuk divalidasi dan disimpan otomatis sebagai "Hadir".

flowchart TD
    A([🟣 Mulai]) --> B[📊 Buka Halaman Scan QR]
    B --> C[📊 Inisialisasi Kamera + Html5QrcodeScanner]
    C --> D[/📥 Scan QR Code Kartu Siswa/]
    D --> E[📊 Kirim POST Request: qr_data]
    E --> F{🔷 Cari Siswa by NIS}
    F -->|Tidak Ditemukan| G{🔷 Cari by ID Siswa}
    G -->|Tidak Ada| H[/📤 Response Error 404: Siswa Tidak Ditemukan/]
    H --> D
    F -->|Ditemukan| I{🔷 Cek Permission: Siswa di Kelas Wali?}
    G -->|Ditemukan| I
    I -->|Beda Kelas| J[/📤 Response Error 403: Bukan Kelas Anda/]
    J --> D
    I -->|Kelas Sesuai| K{🔷 Sudah Absen Hari Ini?}
    K -->|Ya| L[/📤 Response: Siswa Sudah Presensi/]
    L --> D
    K -->|Belum| M[💾 Simpan Presensi: Status Hadir]
    M --> N[/📤 Response Sukses + Nama Siswa/]
    N --> O{🔷 Lanjut Scan?}
    O -->|Ya| D
    O -->|Tidak| P([🟣 Selesai])
4

Lihat Riwayat Presensi

Wali Kelas dapat melihat riwayat presensi siswa di kelasnya dengan filter berdasarkan tanggal, rentang tanggal, dan status kehadiran. Data ditampilkan dengan pagination.

flowchart TD
    A([🟣 Mulai]) --> B[📊 Buka Menu Riwayat Presensi]
    B --> C[/📤 Tampilkan Halaman dengan Filter Kosong/]
    C --> D{🔷 User Mengisi Filter?}
    D -->|Tidak| E[/📤 Tampilkan Tabel Kosong - Belum Ada Pencarian/]
    E --> Z([🟣 Selesai])
    D -->|Ya| F[/📥 Input Filter: Tanggal atau Rentang Tanggal/]
    F --> G[/📥 Input Filter Status: Hadir, Izin, Sakit, Alpha - opsional/]
    G --> H[📊 Query Presensi + Join Siswa via Rombel & Kelas]
    H --> I{🔷 Ada Filter Tanggal Tunggal?}
    I -->|Ya| J[📊 whereDate tanggal]
    I -->|Tidak| K{🔷 Ada Filter Rentang?}
    K -->|Ya| L[📊 whereBetween tanggal_mulai - tanggal_selesai]
    K -->|Tidak| M[📊 Tanpa Filter Tanggal]
    J --> N
    L --> N
    M --> N
    N{🔷 Ada Filter Status?} -->|Ya| O[📊 where status = filter]
    N -->|Tidak| P[📊 Ambil Semua Status]
    O --> Q[📊 Paginate 20 per Halaman]
    P --> Q
    Q --> R[/📤 Tampilkan Tabel Riwayat + Pagination/]
    R --> Z
5

Pengajuan Guru Pengganti

Ketika Wali Kelas berhalangan hadir, ia dapat mengajukan permintaan Guru Pengganti ke Admin. Pengajuan memerlukan tanggal (minimal hari ini), alasan, dan dokumen pendukung wajib. Admin kemudian memproses pengajuan.

flowchart TD
    A([🟣 Mulai]) --> B[📊 Buka Menu Tugas Pengganti]
    B --> C[/📤 Tampilkan Daftar Pengajuan Sebelumnya/]
    C --> D[/📥 Klik Buat Pengajuan Baru/]
    D --> E[/📥 Input Tanggal Penggantian/]
    E --> F[/📥 Input Alasan Ketidakhadiran/]
    F --> G[/📥 Upload Dokumen Pendukung - WAJIB/]
    G --> H{🔷 Validasi Input}
    H -->|Tanggal di Masa Lalu| I[⚠️ Error: Tanggal Harus >= Hari Ini]
    I --> E
    H -->|Dokumen Tidak Ada| J[⚠️ Error: Dokumen Wajib Diupload]
    J --> G
    H -->|Valid| K[💾 Simpan File Dokumen ke Storage]
    K --> L[💾 Simpan Pengajuan ke DB: Status = Pending]
    L --> M[/📤 Tampilkan Pesan Sukses/]
    M --> N[📊 Pengajuan Masuk ke Daftar Admin]
    N --> O{🔷 Keputusan Admin}
    O -->|Disetujui| P[📊 Admin Assign Guru Pengganti + Status Disetujui]
    P --> Q[📊 Guru Pengganti Melihat Tugas di Dashboard]
    O -->|Ditolak| R[📊 Admin Input Keterangan Penolakan]
    R --> S[/📤 Status Ditolak + Alasan Tampil di Daftar Wali/]
    Q --> T([🟣 Selesai])
    S --> T
6

Pengajuan Rekap Presensi (Bulanan/Semester)

Wali Kelas mengajukan rekap presensi ke Kepala Sekolah untuk periode bulanan atau semester. Setelah disetujui, Wali Kelas dapat mengunduh rekap dalam format PDF yang berisi statistik lengkap per siswa.

flowchart TD
    A([🟣 Mulai]) --> B[📊 Buka Menu Pengajuan Rekap]
    B --> C[/📤 Tampilkan Daftar Pengajuan Sebelumnya/]
    C --> D[/📥 Pilih Tipe: Bulanan atau Semester/]
    D --> E[/📥 Pilih Bulan dan Tahun/]
    E --> F{🔷 Cek Duplikat Pengajuan}
    F -->|Sudah Ada| G[⚠️ Error: Pengajuan Periode Ini Sudah Ada]
    G --> D
    F -->|Belum Ada| H[💾 Simpan Pengajuan: Status = Pending]
    H --> I[/📤 Tampilkan Pesan Sukses/]
    I --> J[📊 Pengajuan Masuk ke Kepala Sekolah]
    J --> K{🔷 Keputusan Kepala Sekolah}
    K -->|Ditolak| L[📊 Keterangan Penolakan]
    L --> M[/📤 Status Ditolak Tampil di Daftar/]
    K -->|Disetujui| N[📊 Set acc_by + acc_date]
    N --> O{🔷 Wali Kelas Klik Download PDF?}
    O -->|Ya| P[📊 Ambil Data Siswa via Rombel + Kelas]
    P --> Q[📊 Query Presensi Sesuai Periode]
    Q --> R[📊 Hitung Statistik per Siswa: H, I, S, A]
    R --> S[📊 Generate PDF via DomPDF]
    S --> T[/📤 Download File PDF Rekap/]
    T --> U([🟣 Selesai])
    M --> U
    O -->|Tidak| U
7

Lihat Data Siswa & Kartu Siswa QR

Wali Kelas dapat melihat daftar siswa aktif di kelasnya, mencari berdasarkan nama, dan mencetak Kartu Siswa yang berisi QR Code untuk scan presensi.

flowchart TD
    A([🟣 Mulai]) --> B[📊 Buka Menu Data Siswa]
    B --> C[📊 Ambil Periode Semester Aktif]
    C --> D[📊 Query Siswa via Rombel dimana Kelas = Kelas Wali]
    D --> E{🔷 Ada Keyword Pencarian?}
    E -->|Ya| F[📊 Filter: nama_siswa LIKE keyword]
    E -->|Tidak| G[📊 Ambil Semua Siswa]
    F --> H[📊 Paginate 15 per Halaman]
    G --> H
    H --> I[/📤 Tampilkan Tabel Daftar Siswa/]
    I --> J{🔷 Aksi per Siswa}
    J -->|Lihat Kartu| K{🔷 Cek: Siswa di Kelas Wali?}
    K -->|Tidak| L[⚠️ Error 403: Akses Ditolak]
    K -->|Ya| M[/📤 Tampilkan Kartu Siswa + QR Code NIS/]
    M --> N{🔷 Cetak Kartu?}
    N -->|Ya| O[🖨️ Print Kartu Siswa]
    N -->|Tidak| P([🟣 Selesai])
    J -->|Kembali| P
    L --> P
    O --> P
