Tabel 1. Deskripsi Use Case Melakukan Login
Nama use case Melakukan Login
Kebutuhan Pengguna harus dapat mengakses sistem dengan kredensial yang valid
Tujuan Memberikan akses ke dalam sistem sesuai hak akses Admin
Prekondisi Admin belum masuk ke dalam sistem (berada di halaman login)
Kondisi Gagal Username atau password salah, atau akun tidak terdaftar/tidak aktif
Aktor Utama Admin
Arus Utama 1. Pengguna membuka halaman login
2. Mengisi username dan password
3. Sistem memverifikasi validitas data
4. Pengguna diarahkan ke dashboard Admin
Post Kondisi Admin berhasil masuk ke sistem dan mendapatkan akses penuh
