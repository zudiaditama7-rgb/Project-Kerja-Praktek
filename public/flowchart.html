1. Flowchart Autentikasi & Role-based Routing

flowchart TD

8. Presensi via QR Code Scan

flowchart TD
    A([Wali Kelas / Guru Pengganti]) --> B[Buka Halaman Scan QR]
    B --> C[Inisialisasi Kamera + Html5QrcodeScanner]
    C --> D[Scan QR Code Siswa]

    E --> F{Cari Siswa by NIS}

    G -->|Tidak Ada| H[Response 404]
    F -->|Ditemukan| I{Cek Permission}

    I -->|Wali + Beda Kelas| J[Response 403]
    I -->|OK| K{Sudah Absen?}
    K -->|Ya| L[Response: Sudah Presensi]
    K -->|Belum| M[Simpan: status hadir]
    M --> N[Response Sukses]

18. Swimlane: Alur Guru Pengganti

sequenceDiagram
    participant WK as Wali Kelas
    participant SYS as Sistem
    participant ADM as Admin
    participant GP as Guru Pengganti

    WK->>SYS: Ajukan Guru Pengganti
    SYS->>SYS: Simpan status pending
    ADM->>SYS: Lihat daftar pengajuan
    alt Disetujui
        ADM->>SYS: Assign Guru + status disetujui
        SYS->>GP: Tugas muncul di dashboard
        GP->>SYS: Input presensi kelas
        SYS->>SYS: Simpan + tugas selesai
    else Ditolak
        ADM->>SYS: Tolak + keterangan
        SYS->>WK: Status ditolak
    end

19. Swimlane: Alur Pengajuan Rekap

sequenceDiagram
    participant WK as Wali Kelas
    participant SYS as Sistem
    participant KS as Kepala Sekolah

    WK->>SYS: Ajukan rekap bulanan/semester
    SYS->>SYS: Cek duplikat periode
    alt Duplikat
        SYS->>WK: Error duplikat
    else Baru
        SYS->>SYS: Simpan status pending
        KS->>SYS: Buka menu approval
        alt Disetujui
            KS->>SYS: Approve
            WK->>SYS: Download PDF Rekap
            SYS->>WK: File PDF
        else Ditolak
            KS->>SYS: Tolak + keterangan
        end
    end
